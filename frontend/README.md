# DepthWizard: AI Terrain Explorer

Create a modern, professional frontend website called "DepthWizard" for our SIH project.

DepthWizard is an AI-based system for single-view height estimation and 3D terrain flythrough from overhead/satellite images.

Build the frontend only for now. Do not implement the backend, database, authentication logic, or AI model yet.

Create these pages:

1. Landing/Home page

2. Login and Signup pages

3. User Dashboard

4. Image Upload and Preview page

5. AI Analysis/Processing page

6. Depth and Elevation Results page

7. Interactive 3D Terrain Viewer page

8. Projects/Analysis History page

The main user flow should be:

Home → Login → Dashboard → Upload Image → Preview → Start Analysis → Processing → Results → 3D Terrain Viewer → History.

Use a clean, modern technology/scientific visual style suitable for an SIH project. Make the website responsive for both desktop and mobile.

Use sample/dummy data wherever backend data would normally be required. Keep the code organized so that backend APIs can be connected later.
